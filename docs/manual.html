Scouting Report 使い方マニュアル

チーム共有のパフォーマー名簿アプリ ─ ブラウザだけで使えます（アプリのインストール不要）

📍 https://aratama-ship-it.github.io/scouting-report-app/

📌 2026-09-24更新: このアプリは閲覧専用になりました。以前あった☆お気に入り・コメント投稿・選考ステータスのボタン操作はできません（内容は表示されます）。候補の採否やコメントを追加・変更したい場合は、管理者（Arata）に直接伝えてください。

このアプリでできること

  • 登録済みパフォーマー（約260組）の名簿を検索・閲覧
  • 各アーティストの詳細ページで、似たスキルを持つ関連アーティストを発見
  • 誰が☆お気に入りを付けたか、どんなコメントが残っているかを閲覧
  • 毎週自動調査される新規候補と、その選考ステータス（未確認/検討中/連絡済み/採用/保留/見送り）を確認
  • 名簿の変更履歴・集計を確認

はじめかた（初回アクセス）

1上のURLをスマホまたはPCのブラウザで開く

2チームの合言葉を入力して「Unlock」（合言葉は管理者から直接共有されます。このマニュアルには書きません）

💡 2回目以降: 合言葉はブラウザが覚えるので、URLを開くだけですぐ名簿が表示されます。ブックマーク／ホーム画面に追加しておくと便利です。

画面の見かた ─ 4つのタブ

名簿登録アーティストの一覧。検索ボックス（名前・スキル・メモ）とカテゴリ絞り込みが使えます。カードをタップすると詳細ページへ。選考ステータスが「採用」になった候補も、正式な名簿反映前に「Adopted (pending snapshot)」タグ付きでここに先行表示されます。
候補毎週の自動調査で見つかった新規スカウト候補。選考ステータス（未確認/検討中/連絡済み/採用/保留/見送り）・国内/海外の区分・☆コメント数を表示。「Added to roster / Not yet added」のタグで名簿への反映状況がわかります。
履歴名簿の週ごとの変化（追加・削除・変更）の記録。
集計登録数とカテゴリ別の内訳グラフ、スカウトが手薄なジャンルのメモ。

詳細ページで見られること

☆お気に入り

「★ 3」のように、チーム全体で何人が☆したかの件数が表示されます（誰が付けたかはカーソルを合わせると見られます）。ボタンでの追加・削除はできません。付けたい／外したい場合は管理者に伝えてください。

コメント

チームメンバーが残したコメントが名前と日時つきで一覧表示されます。新しいコメントの投稿はアプリからはできません。共有したいメモがあれば管理者に伝えてください。

よくある質問

スマホでも使えますか？
使えます。スマホ・タブレット・PCどれでもOK。画面は自動で最適化されます。
合言葉を忘れました
管理者（Arata）に直接聞いてください。メールやSNSに書き残さないようお願いします。
「Lock」ボタンは何ですか？
ログアウトのようなものです。共用PCで見たあとなど、他人に見られたくないときに押してください。次回また合言葉が必要になります。
InstagramやYouTubeのリンクを押すとどうなりますか？
新しいタブでそのアーティストのページが開きます。アプリの画面はそのまま残ります。
名簿のデータはいつ更新されますか？
週1回（月曜朝）の自動更新です。画面上部に「◯◯◯◯-◯◯-◯◯時点」とデータの基準日が表示されています。候補ステータスが「採用」になったものだけは、次の週次更新を待たずに即座に反映されます。
☆やコメントを追加してほしい／候補を採用にしてほしい
アプリからは操作できません。管理者（Arata）にチャット等で直接伝えてください。まとめて反映されます。

管理者向けメモ（Arata用）

名簿データ更新週次定期タスクが自動実行（tools/promote-candidates.mjs → npm run build → push → Pages反映）。手動更新も同じ手順。
☆・コメント・候補ステータスの実体scouting-report/favorites.csv・comments.csv・candidate-status.csv。本人がExcel/Numbers等で直接編集するか、チャットでAIに伝えて反映（列の形式はPROJECT_NOTES.mdセクションC参照）。
候補の採用candidate-status.csv の該当行を status=採用 に。次回の週次実行で tools/promote-candidates.mjs が自動的に名簿へ昇格する（それまではアプリ上に先行表示のみ）。
合言葉の変更.secret を書き換え → npm run build → push → チームに新しい合言葉を連絡。
コミット禁止物生の名簿md・合言葉（.secret）は公開リポジトリに入れない。
